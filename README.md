## IP：38 段美国原生 IP，和“住宅 IP”不是一回事

官方说明是分配 38 段美国原生 IP，或者提供 DNS 解锁美国区流媒体，Netflix、Disney+ 这类平台在列。

原生 IP 的含义是 IP 的注册地和机房所在地一致，不是广播过来的二手段。它对流媒体识别、部分平台的地域判断有实际帮助。但它和住宅 IP 是两码事：原生 IP 仍然是机房属性，在平台风控体系里的权重不如家宽住宅 IP。做跨境电商、需要“看起来像当地家庭用户”的业务，原生 IP 解决不了这个问题。

另外，多个 IP 检测数据库对同一个 IP 的判定经常不一致，一个库说是 ISP，另一个库说是数据中心，这种事在低价 VPS 圈很常见。看到商家宣传“原生”“双 ISP”，把它当成一个待验证的属性，别当成风控豁免。

500Mbps 的意义在多线程、机房本地传输、以及给突发流量留的余量。你要是指望单线程从国内拉文件跑到 60MB/s，任何一家美西低价机都给不了。

## FAQ

**CN2 GIA 和普通 BGP 差在哪？**
差在回国路径。普通 BGP 国际线路走运营商常规出口，晚高峰容易拥堵丢包；CN2 GIA 走电信精品承载网，路径更短、调度优先级更高，晚高峰的稳定性差距最明显。代价是价格，同配置通常贵 2 到 4 倍。

**500Mbps 端口，国内下载能跑多少？**
单线程受国际出口限制，通常跑不到端口标称值，具体数字取决于你所在省份、运营商和测试时段。想看真实值，用测试 IP 自己拉一个文件测，别信任何测评里的截图数字，包括这篇。

**能不能退款？**
不能。公开条款写明不支持退款。第一次买建议先月付验证，别直接上年付。

**月付还是年付？**
年付便宜约一半，但配置会降一档，而且不能退。先用月付 ¥50 跑一周，确认线路在你本地稳定，再转年付。季付 ¥99 是折中方案，比月付省 34%。

**德国、英国机房有吗？**
有，法兰克福和伦敦。套餐结构和圣何塞不一样，价格另算，如果你要的不是美西，去看对应机房的产品页。
